# RulesGate

Правила сервера в нативном окне Minecraft, до входа игрока в мир. Кто не принял — отключается, кто принял — больше не видит правила, пока вы их не поменяете.

[English version](README.md)

## Возможности

- Правила показываются во время подключения, до загрузки мира: не нужно ничего замораживать и запрещать
- Кнопки «Принимаю» и «Не принимаю», окно не закрывается по Escape
- Правила на языке клиента игрока: `rules/ru.yml` для русского клиента, `rules/de.yml` для немецкого и так далее
- Поменяли правила и подняли `rules-version` — их снова спросят у всех, у игроков онлайн сразу после `/rules reload`
- Каждое принятие записывается с версией и временем, `/rules check <игрок>` показывает запись
- `/rules` открывает правила в игре в любой момент
- Без базы данных: отметки хранятся в данных самого игрока
- Форматирование MiniMessage, сообщения на русском и английском

## Чем отличается от ванильного кодекса поведения

С 1.21.9 ванильный сервер умеет показывать кодекс поведения обычным текстом. RulesGate добавляет форматирование, запись о том, кто и когда принял какую версию, повторный запрос после изменения правил, `/rules` в игре и понятное сообщение тем, кто отказался.

## Установка

1. Скачайте jar со страницы [Releases](https://github.com/m1haos/RulesGate/releases) и положите в `plugins/`.
2. Запустите сервер. В `plugins/RulesGate/` появятся `config.yml`, `rules/` и `lang/`.
3. Напишите свои правила в `rules/ru.yml` (и на других языках, если нужно), выполните `/rules reload`.

Для русских сообщений администрации поставьте в `config.yml` значение `language: ru`.

## Команды и права

| Команда | Право | По умолчанию | Что делает |
|---|---|---|---|
| `/rules` | `rulesgate.command.rules` | все | Прочитать правила |
| `/rules reload` | `rulesgate.command.reload` | op | Перезагрузить настройки, правила и сообщения; спросить игроков онлайн, если `rules-version` вырос |
| `/rules check <игрок>` | `rulesgate.command.check` | op | Какую версию правил принял игрок и когда |

`rulesgate.admin` включает оба админских права.

## Как поменять правила

1. Отредактируйте файлы в `rules/`.
2. Поднимите `rules-version` в `config.yml`, например с `1` на `2`.
3. Выполните `/rules reload`. Игроки онлайн увидят новые правила сразу, остальные — при следующем входе.

Исправить опечатку, не спрашивая всех заново: поменяйте текст и не трогайте `rules-version`.

## Требования

- Paper 26.2
- Java 25

В сети на Velocity или BungeeCord каждый сервер хранит отметки отдельно. Ставьте RulesGate на тот сервер, куда игроки попадают первым.

## Сборка

```
./gradlew build
```

Jar появится в `build/libs/`.

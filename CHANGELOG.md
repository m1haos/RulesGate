# Changelog

## [1.0.0] — 2026-09-29

First release.

### Added

- Rules dialog during connection, before the player enters the world, with accept and decline buttons
- Rules per client language from `rules/<language>.yml`
- `rules-version`: raising it asks everyone again, online players right after `/rules reload`
- Acceptance version and time stored with the player, shown by `/rules check <player>`
- `/rules` to read the rules in game
- English and Russian messages
